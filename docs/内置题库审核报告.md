## 二、内容审核结论

逐题对照课程知识点后，**未发现事实性错误、答案与解析矛盾、或明显超出对应知识点范围的题目**。题目覆盖了 Python 入门核心语法与数据结构，代码题均只要求文本作答，符合 V1.0 不执行用户代码的边界。

审核中发现 10 处评分或题干表述问题：其中参考答案本身正确，但在“可接受答案过窄、关键词绑定了任意变量名/示例、题干未要求解释而评分要求解释”等情况下，正确作答可能被误判。已按“明确改善评分公平性、不改变知识点要求”的原则修正如下。

## 三、已修正问题

| 题号 | 修改前 | 修改后 | 原因 |
| --- | --- | --- | --- |
| `q-python-basics-01-02-2` | 填空仅接受 `python --version` | 增加 `python3 --version`、`py --version`；解析同步说明 | Windows/Linux/macOS 上合法的版本查看命令不同，原答案会把正确命令判错 |
| `q-python-basics-01-03-3` | 关键词含 `换行` | 关键词改为 `小码`、`学习`、`两行` | 题目要求按行说明输出，答出两行即可，不应强制使用“换行”一词 |
| `q-python-basics-01-05-3` | 关键词含 `name` | 移除 `name`，保留 `input`、`print`、`你好` | 题目未规定变量名，使用 `uname` 等其他变量名的正确代码不应失败 |
| `q-python-basics-02-03-3` | 关键词含 `两次` | 关键词改为 `abcabc`、`重复`、`字符串` | 题目问“输出是什么？为什么”，答出重复语义即可，不强制“两次”措辞 |
| `q-python-basics-03-02-3` | 题干只问“输出是什么？” | 增加“请说明 and 两侧条件的判断过程。” | 评分关键词要求说明 `and` 两侧条件，题干应明确要求解释 |
| `q-python-basics-03-04-3` | 关键词含 `result` | 关键词改为 `10`、`2 * 3`、`print` | 题目未要求必须先赋值给 `result`，直接 `print(10 + 2 * 3)` 也完全正确 |
| `q-python-basics-04-03-3` | 题干只问“输出是什么？” | 增加“请说明循环条件与 i 的变化。” | 评分关键词要求说明循环条件与自增，题干应明确要求解释 |
| `q-python-basics-05-02-3` | 题干只问“输出是什么？” | 增加“请说明实参如何传给形参、return 如何返回结果。” | 评分关键词要求参数传递与 return 过程，题干应明确要求解释 |
| `q-python-basics-06-02-3` | 题干只问“输出是什么？” | 增加“请说明下标从几开始以及 t[1] 的含义。” | 评分关键词要求下标说明，题干应明确要求解释 |
| `q-python-basics-06-03-3` | 关键词含 `name`、`小码` | 关键词改为 `键`、`值`、`字典` | 题目只要求“给出一个字典例子”，不同示例不应被判错 |

## 四、未修改但建议抽检关注的项

1. **`q-python-basics-01-04-3`**：关键词包含“不会被程序执行”，属于注释的性质而非“两个作用”；参考答案本身完整，但不同措辞可能被严格评分。是否放宽属于评分策略调整，本次未擅自改动。
2. **`q-python-basics-04-02-3`**：关键词包含 `IndentationError`，若学习者只写“语法错误”可能被判定缺失关键词。是否需要同义词评分属于后续评分策略优化。
3. **主观题关键词总分制**：当前规则为关键词覆盖率 ≥80%，短关键词列表（3–4 个）实际上要求全部命中，措辞变化可能影响通过率。这是阶段 9 已确定的评分机制，本次仅修正明显绑定任意变量名/示例的题目，未改变机制。
