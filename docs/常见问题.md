# 常见问题（FAQ）

## 部署与访问

**Q：默认谁能访问小码？**
默认 `BIND_ADDRESS=127.0.0.1`，只有运行 Docker 的这台机器可以通过 `http://localhost:3000` 访问。后端容器不映射宿主机端口。

**Q：如何让局域网内的手机或另一台电脑访问？**
在 `.env` 中设置：

```dotenv
BIND_ADDRESS=0.0.0.0
XIAOMA_ALLOW_REMOTE=true
XIAOMA_ACCESS_PASSWORD=你的强密码
```

然后 `docker compose up -d`。访问 `http://<宿主机IP>:3000`，首次需要输入密码。若后端拒绝启动，请检查这两个变量是否都已设置。

**Q：公网部署需要注意什么？**
必须使用 HTTPS 反向代理（Caddy/Nginx 等），并设置访问密码。不要把 3000 或 8000 端口直接暴露到公网。详见 [Docker 部署指南](Docker部署指南.md)。

**Q：忘记访问密码怎么办？**
修改 `.env` 中的 `XIAOMA_ACCESS_PASSWORD`，执行 `docker compose up -d`。所有旧会话会失效，使用新密码重新登录。密码不保存在数据库中，无法找回。

**Q：为什么登录一段时间后要求重新输入密码？**
登录令牌默认 24 小时过期，或后端容器重启导致内存会话清空。可通过 `XIAOMA_ACCESS_TOKEN_TTL_SECONDS` 调整有效期。

**Q：端口 3000 被占用怎么办？**
修改 `.env` 中 `FRONTEND_PORT`，例如 `FRONTEND_PORT=8080`，重启后访问 `http://localhost:8080`。

## 数据与备份

**Q：我的学习数据保存在哪里？**
全部保存在 Docker 命名卷 `xiaoma_xiaoma-data` 的 `/app/data/xiaoma.db` 中；本地开发默认在 `backend/data/xiaoma.db`。数据不会上传到开发者服务器。

**Q：如何备份？**
设置页 → 数据备份 → 立即备份，然后下载；或执行 `docker compose exec backend python -m app.cli backup-db`。备份位于 `/app/data/backups/`。

**Q：如何恢复？**
先停止后端，再执行恢复命令。系统会自动备份当前数据库，并校验备份完整性。完整步骤见 [Docker 部署指南第 8 节](Docker部署指南.md#8-恢复数据)。

**Q：执行 `docker compose down -v` 会怎样？**
`-v` 会删除命名卷，**全部学习数据、模型配置、备份和密钥都会丢失**。日常停止请使用 `docker compose down`（不带 `-v`）。

**Q：备份数据库后换机器部署，模型 Key 为什么不能用了？**
模型 API Key 依赖 `data/.secret_key` 加密。请同时迁移该文件，或在新环境中重新填写 API Key。

**Q：如何完全重置小码？**
停止容器后删除数据卷（会丢失全部数据）：`docker compose down -v`，再 `docker compose up -d`。请先确认已备份。

## 模型与 AI

**Q：没有配置模型可以使用吗？**
可以。学习档案、计划、每日任务、内置题库测验、错题与复习均可用；AI 教学与 AI 变式题需要模型。

**Q：支持哪些模型服务商？**
DeepSeek、通义千问、OpenAI，以及任意兼容 OpenAI Chat Completions 协议的自定义端点。详见 [模型配置说明](模型配置说明.md)。

**Q：API Key 安全吗？**
API Key 加密存储在本地 SQLite，接口和页面只展示脱敏值，日志不记录完整 Key。请妥善保护数据卷与 `.env`。

**Q：AI 会执行我写的代码吗？**
不会。V1.0 明确不执行用户提交的 Python 代码；代码题只做文本分析，AI 也不会声称运行过代码。

**Q：AI 回复失败会丢消息吗？**
不会伪造成功回复。后端会保存失败状态与已生成内容，界面有失败标识；失败的助手消息不会进入后续上下文。

**Q：使用 AI 时哪些数据会发送出去？**
教学提示词与必要的学习上下文（学习目标、基础、当前知识点、任务/掌握状态、提问内容）会发送给你自己配置的模型服务商。详见 [模型配置说明第 6 节](模型配置说明.md#6-数据发送范围)。

## 学习与测验

**Q：完成任务就算掌握了吗？**
不是。完成每日任务只会把知识点推进到“待验证”。只有知识点测验满足“有效题量 ≥3、全部通过、百分制 ≥90”才会标记为已掌握。

**Q：为什么看不到某个知识点的测验？**
正式测验只包含已学习的知识点；未学习知识点会被后端拒绝。请先完成对应每日任务并标记开始学习。

**Q：错题什么时候再出现？**
错题自动进入复习任务，间隔按 1、3、7、14 天推进；答错重置为 1 天。可在错题本查看到期任务。

**Q：计划调整会立即生效吗？**
不会。调整会生成新的草稿版本，需要手动确认后才生效，旧版本保留可追溯。

## 开发与升级

**Q：为什么后端使用 Python 3.14？**
产品负责人于 2026-11-02 决策将后端从 3.12 升级到 3.14，项目文档与依赖已按 3.14 验证。

**Q：如何升级小码？**
拉取新代码后执行 `docker compose up -d --build`。后端会自动迁移数据库，数据卷保留。升级前建议先备份。

**Q：如何查看日志？**
`docker compose logs -f backend` 或 `docker compose logs -f frontend`。日志已脱敏，不包含完整密钥或聊天内容。

**Q：本地开发如何启动？**
见 [README 本地启动](../README.md#本地启动)：后端 FastAPI + Alembic 迁移，前端 `npm run dev`。本地开发默认访问地址为 `http://localhost:3000`。
