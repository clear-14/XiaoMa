# 小码模型配置说明

小码通过统一的 LLM Provider 接口调用模型。支持 DeepSeek、通义千问、OpenAI 官方接口，以及任意兼容 OpenAI Chat Completions 协议的自定义端点。

## 1. 在哪里配置

启动小码后进入 **设置 → 模型配置 → 添加模型**。

字段说明：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 名称 | 是 | 便于识别的配置名，例如“DeepSeek 日常” |
| 服务商 | 是 | DeepSeek / 通义千问 / OpenAI / 自定义兼容接口 |
| 模型名称 | 是 | 服务商提供的模型 ID，例如 `deepseek-chat`、`qwen-plus`、`gpt-4.1-mini` |
| 接口地址 | 条件 | 自定义服务商必填；其他服务商默认使用内置端点，也可覆盖 |
| API Key | 添加时必填 | 写入后只保存加密值，页面与接口不再显示明文 |
| 温度 | 否 | 默认值由后端设定，范围 0–2 |
| 最大输出 Token | 否 | 控制回复长度 |
| 超时（秒） | 否 | 单次模型调用超时 |
| 设为默认 | 否 | 教学、测验 AI 变式题等使用默认模型 |

## 2. 服务商预设端点

| 服务商 | 默认 Base URL | 常用模型示例 |
| --- | --- | --- |
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat`、`deepseek-reasoner` |
| 通义千问 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-plus`、`qwen-turbo` |
| OpenAI | `https://api.openai.com/v1` | `gpt-4.1-mini`、`gpt-4.1` |
| 自定义兼容接口 | 无（必须填写） | 由服务商提供 |

自定义端点需兼容 `POST {base_url}/chat/completions`，支持流式（`stream: true`）与非流式响应。若端点路径不同，请填写到与官方 OpenAI v1 等价的前缀。

## 3. 保存与密钥安全

- API Key 使用 Fernet 对称加密后存入本地 SQLite；列表中只展示脱敏值（如 `sk-****abcd`）。
- 加密密钥来源：
  - 未设置 `XIAOMA_SECRET_KEY` 时，后端首次启动自动生成 `data/.secret_key`（Docker 下位于数据卷 `/app/data`）；
  - 也可通过 `XIAOMA_SECRET_KEY` 环境变量指定任意口令（后端经 SHA-256 派生）或 44 位 Fernet 密钥。
- **更换加密密钥后，旧 API Key 无法解密**，需在设置页重新填写。
- 备份数据库时请一并保留 `.secret_key`（默认就在同一数据目录）；否则恢复后的 API Key 不可用。
- 接口不会返回完整 Key；日志不记录完整 Key。

## 4. 测试连接

保存后点击 **测试连接**，后端会：

1. 使用该配置发起一次简短对话；
2. 返回成功、耗时与模型回复摘要；
3. 失败时返回明确原因（HTTP 401/403 鉴权失败、404 模型或地址不存在、超时、网络不可达、空回复等）。

测试连接失败不影响配置保存，但该模型无法正常用于教学。

## 5. 默认模型与降级行为

- 同一时间只有一个默认模型；可随时切换。
- 教学对话（Teaching 子图）需要模型；未配置默认模型时返回 409，并提示先到设置页配置。
- 计划、进度、每日任务、错题、复习、资源查询不依赖模型，未配置模型也可使用。
- AI 变式题需要模型；未配置或生成/复核失败时自动改用内置题库，并在测验中明确说明。
- 模型超时、不可用、空回复或流中断时：
  - 返回明确中文错误；
  - 保存 `status=error` 的助手消息（保留已生成部分），不会伪造成功回复；
  - 失败回复不会进入后续上下文。

## 6. 数据发送范围

使用 AI 教学或 AI 变式题时，以下内容会发送到**你自己配置的模型服务商**：

- 系统教学提示词；
- 必要学习上下文：学习目标、当前基础、当前知识点、任务状态、掌握状态、用户的提问；
- 组卷所需的范围与已学知识点信息。

数据保存在本地部署环境中，不会上传到小码开发者服务器。请阅读所使用模型服务商的隐私政策。

## 7. 常见问题

**Q：没有模型还能用吗？**
可以。学习档案、计划、任务、测验（内置题库）、错题与复习均可离线使用；只有 AI 教学与 AI 变式题需要模型。

**Q：为什么添加后列表里看不到完整 Key？**
这是安全设计。完整 Key 只存在于加密数据库中，任何接口都不返回明文。

**Q：提示“无法解密已保存的 API Key”？**
加密密钥发生变化（例如重新部署时未保留 `data/.secret_key` 或修改了 `XIAOMA_SECRET_KEY`）。请在设置页重新填写 Key。

**Q：模型连接成功但教学回复很慢？**
可调低最大输出 Token、选择更快模型，或检查网络。主 Agent 整体超时由 `XIAOMA_AGENT_TIMEOUT_SECONDS` 控制（默认 120 秒）。
